Video Player Controls Test

Test Steps:

  1. Go to /tcm
  2. Ask: "What is a liquidity sweep?"
  3. Wait for video response
  4. Click play on the video
  5. Wait 4+ seconds for controls to fade
  6. Move mouse over the video
  7. Expected: Controls should reappear immediately

What was fixed:

  • Root cause: Stale closure in showControls callback
  • The useCallback captured isPlaying state at render time
  • When video started playing, the callback still had old isPlaying=false
  • Fix: Use a ref (isPlayingRef) that's always current
  • Also added onMouseMove to header and controls divs for redundancy

Open browser DevTools console and paste this to monitor state:

// In DevTools console:
// This will log when controls visibility changes
const observer = new MutationObserver((mutations) => {
  mutations.forEach(m => {
    if (m.attributeName === 'class') {
      const el = m.target;
      if (el.className.includes('opacity-0')) {
        console.log('Controls HIDDEN', new Date().toISOString());
      } else if (el.className.includes('opacity-100')) {
        console.log('Controls VISIBLE', new Date().toISOString());
      }
    }
  });
});

// Find the controls container and observe it
document.querySelectorAll('[class*="transition-opacity"]').forEach(el => {
  observer.observe(el, { attributes: true });
});
console.log('Observing', document.querySelectorAll('[class*="transition-opacity"]').length, 'elements');
