### Wick Size Analysis
**Category:** Entry Patterns

```csharp
// Wick size analysis
double upperWick = High[0] - Math.Max(Open[0], Close[0]);
double lowerWick = Math.Min(Open[0], Close[0]) - Low[0];
double body = Math.Abs(Close[0] - Open[0]);

bool shallowUpperWick = upperWick < body * 0.5;
bool shallowLowerWick = lowerWick < body * 0.5;
bool largeUpperWick = upperWick > body;
bool largeLowerWick = lowerWick > body;
```

### Daily Bias Calculation
**Category:** Market Analysis

```csharp
// Daily bias from previous day close position
private BiasType dailyBias;

if (previousClose > previousHigh * 0.75 + previousLow * 0.25)
    dailyBias = BiasType.Bullish;  // Closed in upper quarter
else if (previousClose < previousHigh * 0.25 + previousLow * 0.75)
    dailyBias = BiasType.Bearish;  // Closed in lower quarter
else
    dailyBias = BiasType.Neutral;
```
